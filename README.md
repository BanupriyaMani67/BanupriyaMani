## Getting Started

Clone the repository:

```bash
git clone https://github.com/banupriyamanu67/Banupriyamani.git
```

Navigate to the project folder:

```bash
cd YOUR_REPOSITORY
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the portfolio.

## Build

To create a production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```

## Deployment

This portfolio can be deployed using Vercel. Connect the GitHub repository to Vercel and deploy the project.
